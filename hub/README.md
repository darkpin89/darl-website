# Langkahsuka — halaman utama artis (langkahsuka.art)

Folder ini ialah website halaman utama. Website DARL ada di folder luar (root repo).

## Tambah artis baru
1. Letak gambar artis dalam `public/artists/` (contoh `namaartis.jpg`).
2. Buka `data/artists.ts`, salin blok DARL, tampal di hujung senarai, tukar nama, link, gambar dan bio.
3. Simpan (commit). Vercel akan update sendiri.

Teks label (nama, tagline, about) dalam `data/label.ts`.

## Vercel
Projek Vercel berasingan, guna repo yang sama, dengan **Root Directory = `hub`**.
